Questions

Good to know

Which drawing should a beginner start with?

Start with the cube. It uses only straight lines, so it is easy to check. Next come the cylinder and the cone. They teach the oval you will need later for the soda can and the mug.

Why does every drawing use one light direction?

When light comes from one side, the side facing away from it is darker. That one rule makes a flat circle look like a ball and a flat rectangle look like a can.

Can I draw these with my child?

Yes. Each form starts from a shape most kids already know, like a square, a circle or a triangle. Draw the same form side by side, then compare how tall and wide yours came out.
