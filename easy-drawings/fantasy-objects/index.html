Easy Fantasy Drawings

10 drawings from the Fantasy Objects path in Paper Coach, easiest first, each one line at a time on paper.

These ten fantasy treasures start with a cauldron, a crystal cluster and a crystal ball, built from round and pointed shapes. The later drawings reuse those shapes for a knight's sword, a potion bottle, an hourglass and a crown. The last one is an open treasure chest, so save it for when the earlier ones feel easy.

Questions

Good to know

Which fantasy drawing should a beginner start with?

Start with the cauldron. It is the first and easiest drawing in the set. Then try the crystal cluster and the crystal ball before moving on to the sword or the crown.

Can kids draw these with a parent?

Yes. The path is marked advanced, so younger kids do best with a grown-up beside them. Draw side by side, do one step each, and compare your pages before going on.

What do I need to draw these?

A pencil, an eraser and plain paper are enough. Press lightly at first, so a wobbly line is easy to fix before you go over it.
